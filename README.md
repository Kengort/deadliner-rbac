\# 🚀 Project Tracker: Система управления проектами



Профессиональное веб-приложение для мониторинга IT-проектов, управления командой и контроля дедлайнов.



\## 📋 Функциональные возможности



\* \*\*Умный Дашборд\*\*: Автоматическая классификация проектов на «Просрочено», «В работе» и «Завершено» на основе дат.

\* \*\*Индикация срочности\*\*: Динамическое изменение цвета прогресс-бара и визуальные паттерны (диагональная штриховка) для критических задач.

\* \*\*RBAC (Ролевая модель)\*\*: Разграничение прав доступа для Администраторов и Работников.

\* \*\*Интерактивный поиск\*\*: Мгновенная фильтрация проектов и сотрудников без перезагрузки страницы.

\* \*\*BYN Локализация\*\*: Полная адаптация финансовых показателей под белорусский рубль.

\## 🛠 Инструкция по развертыванию



\### 1. Подготовка окружения



Убедитесь, что у вас установлен Python 3.8+.



```bash

\# Клонируйте репозиторий

git clone <url\_вашего\_репозитория>

cd project-tracker



\# Создайте виртуальное окружение

python -m venv venv

source venv/bin/activate  # Для Windows: venv\\Scripts\\activate



\# Установите зависимости

pip install -r requirements.txt



```



\### 2. Инициализация базы данных



Проект использует SQLite. Для наполнения базы тестовыми данными (40 сотрудников, 15 проектов) выполните скрипт:



```bash

python seed.py



```



\### 3. Запуск приложения



```bash

python app.py



```



Приложение будет доступно по адресу: `http://127.0.0.1:5000`

\## 🔑 Учетные данные для тестирования (Auth Edition)



В системе преднастроены следующие пользователи:



| Роль | Email (Логин) | Пароль |

| --- | --- | --- |

| \*\*Администратор\*\* | `admin@company.local` | `admin123` |

| \*\*Работник\*\* | `любой email из списка сотрудников` | `password123` |



\### Матрица прав доступа:



\* \*\*Администратор\*\*: Полный CRUD (создание, чтение, обновление, удаление) проектов и сотрудников, просмотр отчетов.

\* \*\*Работник\*\*:

\* Просмотр списка всех проектов.

\* Фильтр «Только мои проекты» (отображает задачи, где пользователь в команде).

\* Просмотр деталей проекта (поля заблокированы для редактирования).

\* Поиск по базе.

\## 🧪 Сценарии для проверки (Test Cases)



1\. \*\*Проверка Expired-логики\*\*: Измените дату окончания активного проекта на вчерашнюю. Проект должен автоматически переместиться в секцию «Просрочено» и окраситься в красный цвет.

2\. \*\*Проверка RBAC\*\*: Зайдите под аккаунтом работника. Убедитесь, что кнопки «Новый проект», «Редактировать» и «Удалить» скрыты.

3\. \*\*Проверка поиска\*\*: Начните вводить ФИО сотрудника в разделе «Сотрудники». Список должен фильтроваться мгновенно.

4\. \*\*Проверка фильтра «Мои проекты»\*\*: Войдите под учетной записью работника, который назначен на 1-2 проекта, и активируйте чекбокс. Лишние карточки должны исчезнуть.

\## 📁 Структура проекта



\* `app.py` — Основная логика Flask и роутинг.

\* `models.py` — Описание моделей SQLAlchemy (Project, Employee, Assignment).

\* `seed.py` — Генератор реалистичных тестовых данных.

\* `templates/` — Jinja2 шаблоны с использованием Tailwind CSS.

\* `static/` — Пользовательские стили и JS-скрипты для поиска.
